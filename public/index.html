// Pipeline

How Vantage Runs

01
Fetch

Render cron triggers at 08:00 UTC. Agent pulls live data from Mantle RPC, RWA.xyz, and DeFiLlama simultaneously.

02
Normalize

Raw data is cleaned and structured into a unified JSON payload. Groq validates and summarizes each layer's output.

03
Synthesize

Claude Sonnet receives the normalized payload and produces a structured research brief — narrative, data, and forward signal.

04
Publish

The brief renders as a live report card. Updated daily. No human in the loop between fetch and publish.
